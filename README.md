# Power BI Retail & Sales Dashboard Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and demonstrates the use of **Microsoft Power BI** to transform, analyse, and visualise retail and sales data. The project focused on converting raw business data into meaningful insights through interactive dashboards and reports that support data-driven decision-making.

## Objectives
- Clean and prepare retail and sales datasets for analysis.
- Create interactive dashboards to explore key business metrics.
- Develop calculated columns and measures using DAX.
- Present insights through effective data storytelling techniques.
- Visualise trends, performance, and geographical sales patterns.

## Skills Demonstrated

### Data Transformation & Cleaning
- Imported data from multiple sources into Power BI.
- Used **Power Query** to:
  - Remove duplicates and errors.
  - Handle missing values.
  - Change data types.
  - Split and merge columns.
  - Create reusable transformation steps.
  - Prepare datasets for reporting and analysis.

### Data Modelling & DAX
- Built relationships between tables to create an effective data model.
- Created **DAX calculated columns** and **measures** to support business analysis.
- Applied calculations for:
  - Total Sales
  - Average Sales
  - Profit Margins
  - Year-to-Date Metrics
  - Sales Growth Analysis
  - Percentage Contributions

### Interactive Reporting
- Designed interactive reports using:
  - Slicers
  - Filters
  - Drill-through functionality
  - Cross-filtering visuals
- Enabled users to dynamically explore sales performance across products, regions, and time periods.

### Data Visualisation
Created a range of visualisations including:
- Bar Charts
- Line Charts
- Pie Charts
- Maps
- KPI Cards
- Tables and Matrix Visuals

These visualisations were used to analyse:
- Sales trends over time
- Product category performance
- Regional sales distribution
- Customer purchasing behaviour
- Revenue and profitability metrics

## Key Learning Outcomes
- Developed practical experience in building end-to-end Power BI solutions.
- Improved understanding of data preparation and transformation processes.
- Applied DAX to create meaningful business calculations.
- Enhanced skills in dashboard design and user experience.
- Learned how to communicate insights effectively through data storytelling.

## Project Focus
The dashboard was designed to transform retail and sales data into clear, actionable business insights. By combining data preparation, modelling, and visualisation techniques, the project demonstrates how Power BI can be used to monitor performance, identify trends, and support strategic decision-making.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modelling
- Data Visualisation
- Retail & Sales Analytics

## Outcome
This project showcases the ability to clean, analyse, and visualise business data using Power BI, while presenting findings through interactive dashboards that support data-driven decision-making and effective storytelling.
